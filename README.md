# Японское Таро — прототип Android

Этот проект содержит главный экран, тестовую галерею 78 арканов и случайную вытяжку 1 или 3 карт. Реальные изображения и толкования пока не добавлены.

## Создание через Android-телефон
1. В браузере откройте github.com и создайте новый **пустой** репозиторий `japanese-tarot` (без README).
2. Откройте репозиторий, выберите **Add file → Upload files** и загрузите файлы из этого архива, сохранив папки. Если браузер не позволяет загрузить папки, используйте Codespaces и загрузите ZIP в рабочее пространство, затем распакуйте его.
3. В репозитории откройте **Actions → Build Android APK → Run workflow**. При первом запуске GitHub может попросить включить Actions.
4. Дождитесь успешной сборки и скачайте artifact `japanese-tarot-debug-apk` из страницы запуска. Распакуйте ZIP и установите `app-debug.apk` на свой телефон.

## Альтернативно через Codespaces
Создайте Codespace в репозитории и откройте терминал. После распаковки файлов выполните:
```
flutter create --platforms=android --project-name japanese_tarot .
flutter pub get
flutter build apk --debug
```
Flutter SDK в Codespaces может потребовать отдельной установки; проще использовать GitHub Actions.

## Важно
APK — тестовая debug-сборка, не для публикации в Google Play. Для релиза понадобится signing, тестирование и AAB.
